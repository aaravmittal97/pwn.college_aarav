
# Challenge cracking passwords

This level simulates this story, giving you a leak of `/etc/shadow` (in `/challenge/shadow-leak`). Crack it (this could take a few minutes), `su` to `zardus`, and run `/challenge/run` to get the flag!
## Solution:

we will crack the password of `/challenge/shadow-leak`with the command `john` and to see them we will run `john --show` after which we will access the zardus user and run `/challenge/run` which will give us the flag

### Commands Run:
