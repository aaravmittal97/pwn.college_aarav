# challenge 3 reading manuals
```
The challenge in this level has a secret option that, when you use it, will cause the challenge to print the flag. You must learn this option through the man page for challenge!
```
## solution:
in this we will open the `man challenge` in which we will get the binary `/challenge/challenge` and the argument `--mtvdvm` by running this we will get the flag.

### commands run:
```
hacker@man~reading-manuals:~$ man challenge
hacker@man~reading-manuals:~$ /challenge/challenge --mtvdvm 832
```
