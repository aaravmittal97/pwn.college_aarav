# CHALLENGE 3 multi-word variables

when setting a variable it shouldn't have space or else it will read the latter as a command so to assign it that value we have to use `"` ,In this level, you'll need to set the variable PWN to COLLEGE YEAH

## solution:

we will set `PWN` as `COLLEGE YEAH` by using `"` for `COLLEGE YEAH` and putting these two equal to each other 

### commands run:

hacker@variables~multi-word-variables:~$ PWN="COLLEGE YEAH"
You've set the PWN variable properly! As promised, here is the flag:
