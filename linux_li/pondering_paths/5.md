# challenge 4 position elsewhere
in the challenge we have to execute the `/challenge/run`,which will give us a specific path which after following we will get the flag
```sh
hacker@dojo:~$ cd /some/new/directory
hacker@dojo:~/some/new/directory$
```
## solution:

in the terminal we have to first execute `/challenge/run`which will give us the correct directory that is `sys/kernel`after navigating through this directory by `cd`command we will execute `/challenge/run` again which will give us the flag.

### commands run:

hacker@paths~position-elsewhere:~$ /challenge/run
Incorrect...
You are not currently in the /proc/131/fd directory.
Please use the `cd` utility to change directory appropriately.
hacker@paths~position-elsewhere:~$ cd /proc/131/fd
hacker@paths~position-elsewhere:/proc/131/fd$ /challenge/run
Correct!!!
/challenge/run is an absolute path, invoked from the right directory!
