# Grepping Live Output

In this challenge, /challenge/run will output a hundred thousand lines of text, including the flag.  we have to grep for the flag!
## Solution:

 We can simply just pipe output of /challenge/run to grep

Use this blob for pasting commands you've run
```sh
/challenge/run | grep pwn.college
pwn.college{IWXldg_fIYn4XHijiIEij54x28z.QX5EDO0wyMzAzNzEzW}
```
