
# Duplicating Piped Data with tee

 This process' /challenge/pwn must be piped into /challenge/college, but we'll need to intercept the data to see what pwn needs from us!
## Solution:

We just run the command but with tee in the middle to redirect it a file error then we can just read the file called error to see what's the problem and get the flag by correcting the 1st command
```sh
 /challenge/pwn| tee error | /challenge/college
Processing...
The input to 'college' does not contain the correct secret code! This code 
should be provided by the 'pwn' command. HINT: use 'tee' to intercept the 
output of 'pwn' and figure out what the code needs to be.
hacker@piping~duplicating-piped-data-with-tee:~$ ls
COLLEGE  PWN  a  asdf  error  h  instructions  myflag  not-the-flag  the-flag
hacker@piping~duplicating-piped-data-with-tee:~$ cat error
Usage: /challenge/pwn --secret [SECRET_ARG]

SECRET_ARG should be "kB5Vg7GY"
hacker@piping~duplicating-piped-data-with-tee:~$ /challenge/pwn --secret kB5Vg7GY | /challenge/college
Processing...
Correct! Passing secret value to /challenge/college...
Great job! Here is your flag:
pwn.college{kB5Vg7GYkm-ZcwgBXJUfBxwYPbF.QXxITO0wyMzAzNzEzW}
```

## Flag: 

```
pwn.college{kB5Vg7GYkm-ZcwgBXJUfBxwYPbF.QXxITO0wyMzAzNzEzW}
```
