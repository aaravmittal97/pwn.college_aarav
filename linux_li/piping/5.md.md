
# Redirecting Input

In this level, we will practice using /challenge/run, which will require we to redirect the PWN file to it and have the PWN file contain the value COLLEGE! To write that value to the PWN file, recall the prior challenge on output redirection from echo!
## Solution:

We just simply  have to create a `PWN` file with value COLLEGE and redirect it to `/challenge/run`
Use this blob for pasting commands you've run
```sh
$ echo COLLEGE > PWN
$ /challenge/run < PWN
```
