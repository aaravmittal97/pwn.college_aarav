
# Named Pipes

we'll need to create a /tmp/flag_fifo file and redirect the stdout of /challenge/run to it. If we're successful, /challenge/run will write the flag into the FIFO!
## Solution:

We have to create a fifo and then just use it like we use `|`
```sh
$ mkfifo /tmp/flag_fifo
$ /challenge/run > /tmp/flag_fifo (on one terminal)
$ cat /tmp/flag_fifo (on other terminal)
You've correctly redirected /challenge/run's stdout to a FIFO at 
/tmp/flag_fifo! Here is your flag:
pwn.college{4AqMg2gfP7paJKMLbDRSSTr_enh.01MzMDOxwyMzAzNzEzW}

```
