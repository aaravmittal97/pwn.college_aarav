
# Redirecting More Output

In this level, `/challenge/run` will once more give us a flag, but _only_ if we redirect its output to the file `myflag`. Our flag will, of course, end up in the `myflag` file!

## Solution:

We can simply just run `/challenge/run` and redirect it's output to the file myflag
Use this blob for pasting commands you've run
```sh
$ challenge/run > myflag
$ cat myflag
[FLAG] Here is your flag:
[FLAG] pwn.college{AXPNHvgOVYi0JulLab4b_Xmi_qG.QX1YTN0wyMzAzNzEzW}
```

## Flag: 

```
pwn.college{AXPNHvgOVYi0JulLab4b_Xmi_qG.QX1YTN0wyMzAzNzEzW}
```
