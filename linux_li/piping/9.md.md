
# Filtering with grep -v 

In this challenge we have to run grep -v to filter all out all lines containing "DECOY" for the flag
## Solution:

just pipe the output to `/challenge/run` to `grep -v` for the flag
```sh
/challenge/run | grep -v DECOY
pwn.college{8UCKGGaRhJ1fEFacjGX5adgvLqK.0FOxEzNxwyMzAzNzEzW}
```

## Flag: 

```
pwn.college{8UCKGGaRhJ1fEFacjGX5adgvLqK.0FOxEzNxwyMzAzNzEzW}
```
