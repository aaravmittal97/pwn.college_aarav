
# Appending Output
In this challenge we have run  /challenge/run with an append-mode redirect of the output to the file /home/hacker/the-flag. The practice will write the first half of the flag to the file, and the second half to stdout if stdout is redirected to the file. If we properly redirect in append-mode, the second half will be appended to the first, but if we redirect in truncation mode (>), the second half will overwrite the first and we won't get the flag!
## Solution:

In this challenge we just have to redirect the output of /challenge/run to `~/the-flag` 
Use this blob for pasting commands you've run
```sh
/challenge/run >> the-flag
pwn.college{UaXB9jIH1Ys-egyxI_-RRyxHXVb.QX3ATO0wyMzAzNzEzW}
```
