# Grepping Errors 

Like the last level, this level will overwhelm we with output, but this time on standard error. We have to grep through it to find the flag!
## Solution:

We can simply just redirect the stderr to stdout and then pipe it to grep 
Use this blob for pasting commands you've run
```sh
/challenge/run 2>&1 | grep pwn.college
pwn.college{49LY0P5ZFH7xDNAnSg8K-fIv4EO.QX1ATO0wyMzAzNzEzW}
```

## Flag: 

```
pwn.college{49LY0P5ZFH7xDNAnSg8K-fIv4EO.QX1ATO0wyMzAzNzEzW}
```
