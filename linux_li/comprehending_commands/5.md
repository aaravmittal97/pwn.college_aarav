challenge 5 comparing files
```
in the challenge we have to differentiate between two files one contains all the fake flags and one contains the real flag which we have to find,these files are in the `/challenge` directory
```

## solution:
first we have to open the `/challenge` directory by cd command then for the flag we will compare the two files in this directory by  command `diff /challenge/decoys_only.txt /challenge/decoys_and_real.txt` through this we will find the diff betwwen the two fileds and that diff is the real flag only.

### commands run :

hacker@commands~comparing-files:~$ cd /challenge
hacker@commands~comparing-files:/challenge$ diff /challenge/decoys_only.txt /challenge/decoys_and_real.txt
