challenge 4 grepping for a needle in a haystack
```
in the challenge we have to find the flag from a file which contains hundred thousand words using grep .
 eg.hacker@dojo:~$ grep SEARCH_STRING /path/to/file
```

## solution:
as we know the flag starts with pwn.college we will invoke the command grep pwn.college which will show all the words containing this and hence we will get our flag.

### commands run:

hacker@commands~grepping-for-a-needle-in-a-haystack:~$ grep pwn.college /challenge/
data.txt
