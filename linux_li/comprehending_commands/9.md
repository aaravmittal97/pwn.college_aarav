# challenge 9 moving files 
```
`mv` command is used to moves files around,in the challenge we have to move the `/flag` file into `/tmp/hack-the planet`,when its done, run `/challenge/run` which will check the things out and give the flag.
```

## solution:
we will move the `/flag` file into `/tmp/hack-the-planet` by `mv` command and run `/challenge/run` after which we will get the flag.

### commands run:

hacker@commands~moving-files:~$ mv /flag /tmp/hack-the-planet
Correct! Performing 'mv /flag /tmp/hack-the-planet'.
/bin/mv: cannot stat '/flag': No such file or directory
hacker@commands~moving-files:~$ /challenge/check
