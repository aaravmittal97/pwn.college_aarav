challenge 2 catting absolute path
in this challange the flag is not copied to the home directory but it can be read with cat at its absolute path

## solution:
here we will invoke the command `cat /flag` as the flag is not copied to the home directory we will follow the absolute path.

### commands run:

hacker@commands~catting-absolute-paths:~$ cat /flag
