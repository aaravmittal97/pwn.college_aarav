
# Challenge 1 name
In this level, `/challenge/run` will print the flag but will swap the casing of all characters (e.g., `A` will become `a` and vice-versa). Can you undo it with `tr` and get the flag

## Solution:
we will first run the command `/challenge/run` which will give us the swapped flag,after which we will change the character case by the command `/challenge/run | tr '[:upper:][:lower:]' '[:lower:][:upper:]'`
which will give us the flag
### Commands run:
```
hacker@data~translating-characters:~$ /challenge/run
Your case-swapped flag:
PWN.COLLEGE{K4Flh0GLRIJmkq12DFiJPnbfZjb.01mXeZnXWYmZaZnZeZw}
hacker@data~translating-characters:~$ /challenge/run | tr '[:upper:][:lower:]' '[:lower:][:upper:]'
yOUR CASE-SWAPPED FLAG:

```

## Flag: 

```
pwn.college{k4fLH0glrijMKQ12dfIjpNBFzJB.01MxEzNxwyMzAzNzEzW}
```
