
# Challenge suspending processes

This level's `run` wants to see another copy of itself running _and using the same terminal_. How? Use the terminal to launch it, then suspend it, then launch another copy while the first is suspended!

## Solution:

we basically just have to run the process in the background by the command `ctrl z` after when we will run `/challenge/run` we will get the flag
### Commands Run:

```sh
hacker@processes~suspending-processes:~$ /challenge/run
I'll only give you the flag if there's already another copy of me running in 
this terminal... Let's check!

UID          PID    PPID  C STIME TTY          TIME CMD
root         162     129  0 20:21 pts/0    00:00:00 bash /challenge/run
root         164     162  0 20:21 pts/0    00:00:00 ps -f

I don't see a second me!

To pass this level, you need to suspend me and launch me again! You can 
background me with Ctrl-Z or, if you're not ready to do that for whatever 
reason, just hit Enter and I'll exit!
^Z
[1]+  Stopped                 /challenge/run
hacker@processes~suspending-processes:~$ /challenge/run
I'll only give you the flag if there's already another copy of me running in 
this terminal... Let's check!

UID          PID    PPID  C STIME TTY          TIME CMD
root         162     129  0 20:21 pts/0    00:00:00 bash /challenge/run
root         169     129  0 20:22 pts/0    00:00:00 bash /challenge/run
root         171     169  0 20:22 pts/0    00:00:00 ps -f

Yay, I found another version of me! Here is the flag:

```
