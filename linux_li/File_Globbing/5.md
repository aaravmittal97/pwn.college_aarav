# multiple globs
```
in this challenge We put a few happy, but diversely-named files in /challenge/files. Go cd there and run /challenge/run, providing a single argument: a short (3 characters or less) globbed word with two * globs in it that covers every word that contains the letter p.
```
## solution:

we will firstly open the `/challenge/files` directory by `cd` and then run the file `/challenge/run` with the argument `*p*` which will give us the flag:

### commands run:
```
hacker@globbing~multiple-globs:~cd /challenge/files
hacker@globbing~multiple-globs:/challenge/files$ /challenge/run *p*
You got it! Here is your flag!
```
## flag:
```
pwn.college{g-sHQTrCJaO7NchTPeSmEAFRcKp.0lM3kjNxwyMzAzNzEzW}
```
