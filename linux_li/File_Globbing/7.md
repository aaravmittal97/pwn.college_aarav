# challenge 7 exclusionary globbing
```
in this challenge go forth to /challenge/files and run /challenge/run with all files that don't start with p, w, or n!
```
## solutions:
we will open the `/challenge/files` directory  by `cd` and then run the file `/challenge/run` with the argument `[!pwn]` which will give the flag

### commands run:
```
hacker@globbing~exclusionary-globbing:~$ cd /challenge/files
hacker@globbing~exclusionary-globbing:/challenge/files$ /challenge/run [!pwn]*
You got it! Here is your flag!
```
