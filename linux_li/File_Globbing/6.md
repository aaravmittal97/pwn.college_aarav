# challenge 6 mixing globs 
```
let's put the previous levels together! We put a few happy, but diversely-named files in /challenge/files. Go cd there and, using the globbing you've learned, write a single, short (6 characters or less) glob that (when passed as an argument to /challenge/run) will match the files "challenging", "educational", and "pwning"!
```
## solution:
we will open the `/challenge/files` directory  by `cd` and then run the file `/challenge/run` with the argument `[cep]*` which will give us the flag:

### commands run:
```
hacker@globbing~mixing-globs:~$ cd /challenge/files
hacker@globbing~mixing-globs:/challenge/files$ /challenge/run [cep]*
You got it! Here is your flag!
```
